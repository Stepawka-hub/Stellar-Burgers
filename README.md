# Stellar Burger

**О проекте:** Учебный проект - онлайн-бургерная, реализованная для улучшения навыков веб-разработки. Приложение предоставляет следующий функционал:

- 🍔 Конструктор бургеров и последующее оформление заказа
- 📊 Лента заказов и общая статистика
- 🚀 Личный кабинет (история заказов, редактирование профиля)

## Технологии

- CSS3/HTML5
- Typescript
- React
- React Router Dom (v6)
- Redux Toolkit
- Storybook
- Jest (Тестирование)
- Cypress (Тестирование)
- Webpack (Сборщик)
- ESLint (Линтер)

## Использование

### Требования

Для установки и запуска проекта, необходим NodeJS v18+.

### Установка зависимостей

Для установки зависимостей, выполните команду:

```bash
npm i
```

### Запуск Development сервера

Чтобы запустить сервер для разработки, выполните команду:

```
npm start
```

### Тестирование (Jest)

Чтобы запустить модульное тестирование, выполните команду:

```
npm run test
```

### Тестирование (Cypress)

Чтобы запустить e2e-тестирование, выполните команду:

```
npm run cypress:open
```

### Запуск Storybook

Чтобы запустить storybook, выполните команду:

```
npm run storybook
```

### Сборка проекта

Чтобы собрать проект выполните команду:

```
npm run build
```
